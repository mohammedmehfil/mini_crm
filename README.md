# mini_crm
A lightweight customer relationship management dashboard built with plain HTML, CSS, and JavaScript.
Run locally
Open index.html in a modern web browser. The app loads Font Awesome from a CDN, so an internet connection is needed for those icons.
Files
- index.html — application pages and layout
- style.css — responsive styling
- script.js — client-side interactions and sample CRM data
Data and privacy
This is a front-end demo. Data is handled in the browser and is not connected to a CRM backend. Avoid entering real customer or confidential information
